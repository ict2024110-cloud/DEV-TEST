# DEV-TEST | Hardware Testing Platform

A modern, responsive web application for testing and monitoring connected hardware devices in real-time.

## Features

### 🖱️ Mouse Tester
- Real-time mouse movement tracking
- Visual X/Y axis display
- Cursor trail visualization
- Button tester (left, right, middle click)
- Scroll wheel tester
- Polling rate display

### ⌨️ Keyboard Tester
- Real-time key detection
- Full virtual keyboard visualization
- Key press history
- N-Key Rollover support

### 🎮 Gamepad Tester
- Support for Xbox, PlayStation, and generic controllers
- Live joystick movement visualization
- Analog trigger pressure display
- Button press tester
- Vibration support testing

### 👆 Touchscreen Tester
- Multi-touch support
- Finger position tracking
- Gesture detection
- Real-time touch points visualization

### 🔌 USB Device Detection
- Connected device listing
- Device type identification
- Live connect/disconnect status

### 💾 Storage Monitor
- Drive health status
- Storage usage visualization
- Read/write speed display
- Animated progress bars

### 🔊 Audio Tester
- Speaker left/right channel test
- Microphone input visualizer
- Real-time sound wave display

### 📊 Performance Dashboard
- CPU usage monitoring
- RAM usage tracking
- FPS monitor
- Internet speed test
- Battery level and charging status
- System information

## Tech Stack

- **React 19** - UI Library
- **Vite** - Build Tool
- **Tailwind CSS 4** - Styling
- **Framer Motion** - Animations
- **Recharts** - Charts & Graphs
- **Lucide React** - Icons

## Deployment

### GitHub Pages

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select source as "GitHub Actions" or "main branch"
4. Your site will be available at `https://yourusername.github.io/repo-name`

### Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Browser Support

- Chrome/Edge (Best support)
- Firefox
- Safari

Note: Some features like Web USB API require secure context (HTTPS) and specific browser support.
